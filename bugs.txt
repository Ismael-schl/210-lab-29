Bug Log:
1. The code was not able to cleanly summarize the events that occurred during the running of the "simulate" function. Fix: Replacing old status messages with summaries of the events that happenned in various weeks. The number and "week" in which every event occurred is cleanly shown to the user.
2. Because algal blooms and angler activity were wiping out the predator populations for all lakes, I had to double the amount of predators that spawned during spawning season.
3. I hadn't considered the case in which lakes had zero fish of a specific group. This would have caused errors when simulate was run on said lakes. To fix this, I added if statements to regulate the events to occuring on a group if and only if there were already fish in that group. This is also more realistic, because fish would not just spawn without fish being present already.
4. I initially had spawning seasons increase species that happened to be the first element of their respective lists. I then changed it to select a random fish species present in the list to reproduce, to have less lopsided data.
