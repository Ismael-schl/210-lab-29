Bug Log:

2. Because algal blooms and angler activity were wiping out the predator populations for all lakes, I had to double the amount of predators that spawned during spawning season.

4. I initially had spawning seasons increase species that happened to be the first element of their respective lists. I then changed it to select a random fish species present in the list to reproduce, to have less lopsided data.
5. I forgot to have bottom feeders increase during spawning season. To fix this, I copied and pasted predator reproduction code and adjusted it to affect bottom feeders.
6. displayLakes provided an extra comma at the end of the fish lists. Fix: a simple address checking if statement now checks if the element is the last element, if not, it adds a comma and a space to the output.
7. In the file-reading portion of the code, I accidentally used the string variable "names" to represent both the lake name and the fish name. I had to use both "names" and "species" instead. 
8. I originally wrote "const" in the map parameter for simulate. I had to take this out, because simulate definitely affects the map.
9. I accidentally had the bottom feeder block check whether the bottom feeder list was empty but then copy from the predator list. I had to change the list that this block affected.
